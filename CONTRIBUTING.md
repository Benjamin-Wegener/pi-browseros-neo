# Contributing

Issues and pull requests are welcome.

1. Fork and create a branch from `main`.
2. Keep changes focused; one topic per pull request.
3. Test the installer: `PI_DIR=$(mktemp -d) bash install.sh`.
4. Note user-visible changes in `CHANGELOG.md`.

When reporting a bug, include your Pi Coding Agent version, your BrowserOS Neo version, and the tool call that failed.
